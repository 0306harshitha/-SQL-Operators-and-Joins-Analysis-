# SQL Operators and Joins Analysis project

## Objective
To demonstrate strong understanding of SQL fundamentals including
operators, filtering, grouping, and join operations using multiple tables.

## Tables Used
- Employees
- Customers
- Orders
- Products

## SQL Concepts Covered
- WHERE, LIKE, IN, BETWEEN
- AND / OR / NOT operators
- ORDER BY, DISTINCT
- Aggregate functions (SUM,COUNT, MIN,MAX, AVG)
- INNER JOIN and LEFT JOIN
- Handling NULL values in joins

## Key Outcomes
- Filtered employees based on department and salary conditions
- Identified customers with and without orders
- Retrieved product and order details using joins
- Demonstrated real-world relational database querying skills

## Tools Used
- SQL Server
